# RoleFuture AI — Architecture

```text
┌──────────────────────────────────────┐
│ Browser                              │
│ Dashboard | Role Detail | Compare    │
└──────────────────┬───────────────────┘
                   │ HTTP
                   ▼
┌──────────────────────────────────────┐
│ FastAPI                              │
│ REST routes + validation             │
└──────────────────┬───────────────────┘
                   ▼
┌──────────────────────────────────────┐
│ Application Services                 │
│ Scoring | Ranking | Comparison       │
│ Explanation / local AI adapter       │
└───────────────┬───────────────┬──────┘
                │               │
                ▼               ▼
┌──────────────────────┐  ┌─────────────────────┐
│ SQLite + SQLAlchemy  │  │ Ollama (optional)    │
│ persistent source    │  │ local LLM           │
│ data + calculations  │  │ explanations only   │
└──────────────────────┘  └─────────────────────┘
```

## Layers

### Presentation

Jinja2 templates, HTML, CSS, and JavaScript render dashboards, role detail pages, activity assessments, and side-by-side comparisons.

### API

FastAPI exposes role retrieval, role analysis, rankings, comparisons, AI explanations, and AI status.

### Analysis

Python services calculate activity-level exposure, automation and augmentation; aggregate role-level metrics; rank roles; and compare roles.

### Data

SQLite persists roles, processes, activities, scoring factors, calculated assessments, skills, and future responsibilities. The scoring engine can fill missing calculations automatically.

### AI explanation

The local Ollama adapter receives only structured application facts. It is not authoritative for numerical scores. When Ollama is unreachable or returns invalid output, deterministic application logic supplies a fallback explanation so the core application continues working.

```text
GET /api/rankings
GET /api/compare?role_1_id=1&role_2_id=2
GET /api/compare/explanation?role_1_id=1&role_2_id=2
```

## Persistence

`rolefuture.db` is a local SQLite database. The seed process is repeatable and skips existing role records, while missing calculated assessments are generated by the scoring engine.

## AI fallback design

```text
Role / comparison request
          ↓
Structured backend facts
          ↓
      Ollama call
       /      \
   success    failure
      ↓          ↓
 valid JSON   deterministic fallback
       \      /
          ↓
          UI
```

This allows the application to demonstrate AI when a local model is available without making the demonstration dependent on a paid or remote API.
